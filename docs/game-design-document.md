# Game design

Target: cinematic third-person open-world crime adventure, Windows first; Android only after device evaluation. Core pillars: responsive traversal, distinct vehicle handling, authored investigation, and persistent consequences. Protagonist Adrian Vale returns to Veyra seeking his missing sister Mara.

Current playable loop: garage conversation → car journey → evidence collection → search escape → garage reward. Search and civilians are simple placeholders. Final target remains six connected regions, five acts, approximately 28–35 authored missions and at least ten measured hours; none of those quantities are claimed as delivered.

Quality gate: finish a polished Iron Harbor mission before expanding the world. No filler used to satisfy duration. No loot boxes, real-money gambling or unlicensed brands.
