# Actual rendered evidence

These JPEGs are compressed copies of untouched Godot viewport captures from tests/production_capture.gd, not generated concept art. Source PNGs, motion frames/GIF and raw performance JSON remain in ignored tests/artifacts. Captured on Windows / RTX 3050 Laptop / Godot 4.6 Vulkan Forward+.

player.jpg: skinned protagonist. car.jpg: modeled Sable GT. district.jpg and 1080p.jpg: warehouse/container lighting and surfaces. pause.jpg / controls.jpg: modal UI without gameplay HUD overlap. aim.jpg / encounter.jpg: basic authored aim pose and security actors; not a finished combat animation pass.

The capture harness positions actors for representative views. These screenshots do not prove a human end-to-end playthrough. Motion deformation is separately tested; the input-driven mission route is exercised by tests/mission_playthrough.gd.
